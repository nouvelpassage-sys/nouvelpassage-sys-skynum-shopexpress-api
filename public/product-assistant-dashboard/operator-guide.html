Nouvel Amour

Інструкція Telegram-бота

До панелі

1. Основний сценарій

  1. Зробіть одне чітке фото реального товару.
  2. Надішліть фото в Telegram-бот Nouvel Product Assistant.
  3. У підписі до фото напишіть ціну й коротку підказку.
  4. Перевірте картку, яку повернув бот.
  5. Якщо все добре, натисніть Створити в SalesBox.
2500 букет у ніжній гамі
690 іграшка ведмежа
850 аромасвічка Amber driftwood
1900 спатифілум у кашпо, 2 шт

2. Що перевірити

  • Назва має бути креативною, бажано з легким французьким настроєм.
  • Категорія має бути реальною: букети, квіти в коробках, рослини, арома товари, іграшки, листівки або декор.
  • Ціна й фото мають бути правильними.
  • Опис не має перелічувати склад букета або звучати як технічний райдер.
  • Для кімнатних рослин бажано вказувати кількість, якщо вона відома.

3. Кнопки й команди

Лише чернетка

/redo

/rewrite
переписати опис
/premium
зробити назву й опис преміальнішими
/shorter
скоротити опис
/fix
виправити слабкі місця
/status
перевірити режим SalesBox і сховище фото

4. Що відбувається після публікації

Бот виконує дві дії: створює товар у SalesBox через API та додає цю ж картку у ShopExpress import queue.

SalesBox live write: увімкнено
ShopExpress live write: вимкнено
ShopExpress import queue: увімкнено

Поточна черга ShopExpress:

data/product-assistant/shopexpress-pending-import.csv

5. SalesBox → ShopExpress

Щоб сформувати повний імпорт із SalesBox у ShopExpress, запустіть:

node scripts/export-salesbox-to-shopexpress-import.mjs

Результат:

data/product-assistant/salesbox-to-shopexpress-import.csv

6. Етап 2

Етап 1 завершено: Telegram → SalesBox працює, ShopExpress отримує чергу імпорту. Етап 2: підтвердити офіційний ShopExpress API endpoint і замінити CSV-чергу на live-синхронізацію.
