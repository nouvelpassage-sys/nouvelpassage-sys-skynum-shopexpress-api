# Nouvel Product Assistant: інструкція оператора

Це робоча інструкція для флористів і адміністратора. Основна ідея проста: **телефон у руках, Telegram-бот приймає фото, ціну й коротку підказку, далі створює картку для SalesBox**. ShopExpress підключений другим каналом через чергу імпорту.

## 1. Основний сценарій

1. Зробіть одне чітке фото реального товару.
2. Надішліть фото в Telegram-бот `Nouvel Product Assistant`.
3. У підписі до фото напишіть ціну й коротку підказку.
4. Перевірте картку, яку повернув бот.
5. Якщо все добре, натисніть **Створити в SalesBox**.

Формат підпису:

```text
2500 букет у ніжній гамі
690 іграшка ведмежа
850 аромасвічка Amber driftwood
1900 спатифілум у кашпо, 2 шт
```

Текст без фото бот не приймає як новий товар. Якщо потрібно виправити картку, використовуйте кнопки або команди.

## 2. Що перевірити перед публікацією

- Назва має бути креативною, бажано з легким французьким настроєм.
- Назва не має бути сухою на кшталт `Букет півоній`, `Рожева композиція`, `Кімнатна рослина`.
- Категорія має бути реальною: `Букети`, `Квіти в коробках`, `Кімнатні рослини`, `Арома товари`, `Іграшки`, `Листівки`, `Декор та подарунки`.
- Ціна має бути правильною.
- Фото має бути готове.
- Опис не має перелічувати склад букета.
- Опис не має звучати як технічний райдер.
- Для кімнатних рослин бажано вказувати кількість, якщо вона відома.

## 3. Кнопки й команди

**Створити в SalesBox**  
Створює товар у SalesBox. Після цього картка також додається в ShopExpress import queue.

**Лише чернетка**  
Залишає картку без публікації.

**Перестворити** або `/redo`  
Створює картку заново з того самого фото.

**Переписати опис** або `/rewrite`  
Переписує текст без зміни суті товару.

**Преміальніше** або `/premium`  
Піднімає тон назви й опису.

**Коротше** або `/shorter`  
Скорочує опис.

**Виправити** або `/fix`  
Виправляє слабкі місця: категорію, сухий опис, невдалу назву.

**/status**  
Показує, чи увімкнений запис у SalesBox і чи працює сховище фото.

## 4. Що відбувається після натискання “Створити в SalesBox”

Бот виконує дві дії:

1. **SalesBox**: створює товар через API.
2. **ShopExpress**: додає цю ж картку в CSV-чергу імпорту.

Поточний режим:

```text
SalesBox live write: увімкнено
ShopExpress live write: вимкнено
ShopExpress import queue: увімкнено
```

Це означає, що SalesBox уже працює напряму, а ShopExpress поки безпечно отримує готові рядки у файл:

```text
data/product-assistant/shopexpress-pending-import.csv
```

## 5. Перенесення SalesBox → ShopExpress

Якщо потрібно синхронізувати всі поточні товари з SalesBox у ShopExpress, запустіть:

```bash
node scripts/export-salesbox-to-shopexpress-import.mjs
```

Файл буде створено тут:

```text
data/product-assistant/salesbox-to-shopexpress-import.csv
```

У файл потрапляють назва, опис, ціна, SKU, категорія, фото, SEO, наявність, мінімальне замовлення `1` і кратність `1`.

## 6. Коли зупинитися й покликати відповідального

Покличте відповідального, якщо:

- бот визначив неправильну категорію;
- фото не завантажилося;
- ціна неправильна;
- опис виглядає технічним або дивним після `/fix`;
- SalesBox не створив товар;
- ShopExpress імпорт хоче змінити забагато існуючих товарів.

## 7. Етап 2

Етап 1 завершено: Telegram → SalesBox працює, ShopExpress отримує чергу імпорту.

Етап 2: підтвердити офіційний ShopExpress API endpoint для створення або оновлення товарів і замінити CSV-чергу на live-синхронізацію.
